# Тренер

Личное Android-приложение для силовых тренировок (HTML/CSS/JS + Capacitor). Программа, техника с фото, подходы, прогрессия весов, прогресс.

Правила работы и сборки — в [AGENTS.md](AGENTS.md), текущее состояние — [docs/STATUS.md](docs/STATUS.md). Релизы с APK — в разделе Releases; в приложении «Ещё → Проверить обновление».
Фото упражнений — [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (public domain).
