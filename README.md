# Тренер

Личный трекер силовых тренировок: программа на 4 дня, техника упражнений с фото, подходы и прогрессия весов, путь к первому подтягиванию.

Открыть: https://godoffear.github.io/trener/

Чистый HTML/CSS/JS без сборки и без сервера, данные хранятся в браузере (IndexedDB), бэкап — файлом JSON.
Фото упражнений — [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (public domain).
