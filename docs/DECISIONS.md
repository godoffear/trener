# DECISIONS — принятые решения

- Версия одна, в корне репозитория; история версий = история коммитов (с 2026-11-15). Старые `versions/vN` — только локально в `_archive/`.
- Подтверждение владельца нужно только перед выпуском версии (релиз на GitHub).
- Приложение обновляется через `releases/latest` (не через сайт github.io); релиз только обычный, не pre-release.
- Отдых: 120 с тяжёлые базовые, 75 с изоляция, 60 с пресс; лимит дня 70 мин — только предупреждение («нужно качество»).
- Веса: прогрессия идёт по реальным плитам зала (`STACKS`); при большом скачке плиты сначала добавляются повторы.
- Предложения Codex по убиранию упражнений из программы отклонены (2026-11-08).
- Пятница: добавлен наклонный жим в рычажном тренажёре; разведение гантелей на наклонной оставлено (2026-11-12).
- Переходить к другому упражнению можно в любой момент точками вверху экрана тренировки (кнопки «поменять местами» нет).
- Сайт godoffear.github.io/trener (старый PWA 0.20) приложению не нужен, но файлы `sw.js`, `manifest.webmanifest`, `dev/` не удалены.
- Подпись APK: стандартный debug-ключ `~/.android/debug.keystore` на этом Mac; ключи в git не попадают.
- Суперсет двух упражнений на одну мышцу (разгибание из-за головы + на блоке) убран: повторы падали. Теперь из-за головы идёт первым и отдельно, разгибание на блоке в суперсете с прессом на блоке (2026-11-16, идея владельца).
- Codex (ChatGPT) получил полные права: код, сборка, подпись ключом владельца с этого Mac, пуш и релизы (2026-11-20; Claude Code может пропасть). Ограничение «только дизайн» снято.
- Ночная копия: снимок данных лежит в файле `autobackup.json` во внутренней папке приложения, токен GitHub и репозиторий — в SharedPreferences (те же, что введены в настройках); задача WorkManager раз в 24 ч, первый запуск в ближайшие 23:59; если Android задержал задачу за полночь (до 03:00), копия записывается прошлым днём; `latest.json` обновляется каждый день (2026-11-21).
- Hermes (Альфред) получил полные права: правки, сборка, подпись, релизы (2026-11-23). Ключ подписи лежит только на Mac владельца: Hermes подписывает либо на Mac, либо после того, как владелец сам передаст ему ключ вне репозитория.
- Косые мышцы (2026-11-24, идея владельца): диагональные подъёмы ног в упоре (Пн), дровосек на блоке (Чт), боковая планка в суперсете (Пт); скручивания на блоке остаются (Пн, Чт); пресс-ролик не нужен.
