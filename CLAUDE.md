# Тренер — контекст для Claude Code

Личный трекер силовых тренировок (PWA) для Андрея. Живёт на GitHub Pages: https://godoffear.github.io/trener/
Андрей — начинающий разработчик, пишет по-русски, часто голосом. Отвечай по-русски, коротко, по делу, обращайся по имени. Объясняй простым языком.
Питание — в отдельном приложении «Рацион» (репозиторий `godoffear/racion`), здесь его нет. Шаги и ходьбу Андрей считает в других приложениях — здесь только тренировка.

## Главные правила работы
- **Сначала согласуй, потом меняй.** На просьбу об изменениях — план пунктами, дождись «да». Мелкие исправления ошибок можно сразу, но скажи, что исправил.
- Коммить прямо в `main` — сайт обновляется только из `main`. После пуша проверь, что Pages собрался.
- Каждый выпуск: подними `APP_VERSION` в `js/app.js` **и** `VERSION` в `sw.js` (иначе телефон не заберёт обновление).
- Не ломай сохранённые данные: база IndexedDB `trener`, новые поля настроек — в `defaultSettings()` с безопасными значениями, старые не переименовывай.
- Проверяй вёрстку на 360×780 (Samsung A37) и горизонтально 780×360: `python3 dev/check.py [ГГГГ-ММ-ДДTЧЧ:ММ]`.
- Меньше шума: на экранах только то, что нужно в зале; редкое — во вкладке «Ещё» или в окне правки.

## Как устроен репозиторий (без сборки — файлы правятся напрямую)
- `index.html` — оболочка, подключает `css/app.css` и скрипты.
- `js/exercises.js` — справочник `EX`: фото из free-exercise-db (public domain) в `img/ex/<img>/0.jpg|1.jpg` — везде свёрнуты под «Фото» (0.5 убирал, 0.5.1 Андрей попросил вернуть), техника по-русски, подсказка, темп, дыхание, ошибки, замены. `type`: `w` вес, `bw` свой вес, `time` секунды, `assist` помощь (гравитрон). Машину Смита, прыжки и упражнения на ягодицы не добавлять.
- `js/program.js` — программа по умолчанию (`defaultProgram`, `PROGRAM_V`=6, 0.17, решение Андрея: Пн A грудь/плечи/трицепс — жим 4×6–10 + суперсет `calf` в паузах жима; Вт B спина/бицепс — гравитрон 4, row, lat_pd, rear_fly, curl 4, rev_crunch; Чт C ноги — leg_press 4, leg_curl, leg_ext, hyper, calf, rev_crunch; Пт D всё тело — leg_press 3, chest_press, gravitron 3, row, lat_raise, curl + суперсет `rope_ovh`; дни недели не менять; убраны grav_neg, face_pull, plank, bench_lr, goblet, db_row, sldl). `ss: true` у пункта программы — суперсет: делается в паузах предыдущего, в `dayMinutes` времени не добавляет, подход не сбрасывает таймер отдыха основного. Время ≈ A 58 / B 61 / C 58 / D 55 мин. Турника нет — без виса и подъёма ног в висе; отдых база 90 с / изоляция 60 с / удержания 45 с. `dayMinutes` (подход: базовое 65 с / изоляция 90 с + отдых + переход 2,5 мин — сверено по тренировкам 5 и 6 окт), предупреждение при > `MAX_MIN`=70. Переезд в `dbLoad`: v<6 — программа заменяется (дни недели остаются). Скручивания в тренажёре и на коленях на блоке Андрей не любит. Кардио-разминки и растяжки нет: один лёгкий подход (пустой гриф, лёгкие гантели).
- 0.17 «Гравитрон — дополнительные подходы»: кнопка на последнем экране любой тренировки (`wo-extra`), пункт `extra:true` с `plan.sets=0`: по желанию, без «осталось подходов», отдых 90 с; в `exHistory` не попадает (прогрессия, «В прошлый раз», `negReady` их не видят). «Закрепить замену»: если упражнение уже заменяли в прошлую тренировку этого дня, после выбора замены `wo-pin` предлагает поставить её в программу (только в этом дне). На последнем подходе изоляции — подсказка «почти до отказа». Окно «Закрепить» открывается поверх листа без `closeSheet` (иначе popstate его закроет).
- Копия: файл `Тренер_ГГГГ-ММ-ДД_ЧЧ-ММ.json`.
- `js/db.js` — IndexedDB (`kv`, `workouts`, `walks` — не используется, `body`), всё читается в `D`; бэкап JSON.
- `js/app.js` — экраны `vToday` (полоса недели кликабельна: `selDay`, стрелки и свайп; прошлый день — `vDone` или «пропущено» + «Сделать сегодня»; во вт/пт `vPull` — путь к подтягиванию), `vProgram` (просмотр; правка по кнопке «Изменить»), `vStats`, `vMore` (вес, дни недели, бэкап, сброс). Нижние листы — `openSheet`/`closeSheet` (кнопка «Назад» закрывает), клики — по `data-a`.
- `js/workout.js` — экран тренировки (`tab='workout'`, нижнее меню скрыто): вопросы перед стартом (`sheetCheck`, облегчённо = подход меньше), по упражнению на экран, ввод подхода (`entry`, ± по шагу), разминочный подход перед базовыми — мелкая строка с галочкой, после отметки сворачивается в «✓ разминка» (`warm`, в статистику и расчёт времени не идёт), часы всей тренировки в липкой шапке (`clockLoop`, чистое время `activeMs` = сейчас − start − `paused`), простой 10 мин без действий (`checkIdle`, `lastAct`, `touch`) — пауза: часы встают на последнем действии, окно «Продолжить / Завершить», простой в длительность не идёт (`paused`, `pauseAt`; у сделанной тренировки длительность = end − start − paused), таймер отдыха (`restUntil`; конец — `alarm`: выбранный звук (`js/sounds.js`, 10 на выбор в «Ещё» → «Звук отдыха» + громкость тихо/средне/громко + писк за 3-2-1 с по переключателю), вибрация и системное уведомление `notify` — Андрей слушает музыку громко, прежний резкий сигнал бил по ушам (теперь это вариант «Громкий»); звук играет в конце отдыха и в конце таймера планки, в конце всей тренировки звука НЕТ — так хочет Андрей; один тик раз в секунду `tick`, в фоне не крутится — Андрей жаловался на нагрев), автопереход к следующему упражнению через 7 с после последнего по плану подхода (`autoNext`, «Остаться» отменяет), экран не гаснет (`keepAwake`), таймер для упражнений на время (`hold`: «▶ Старт N с» → до конца пишется цель, «Стоп» — прошедшие секунды), «Заменить» на сегодня, «Дискомфорт» (2 раза подряд — предложить замену в программе), заметка, калькулятор блинов, итог с рекордами (`findRecords`, `sheetSummary`), «Отменить без записи» (`wo-cancel`). В сделанном дне — «Удалить» (`wdel`). Незавершённая тренировка — `D.active`, сохраняется после каждого действия.
- Голосовой ввод и «Запас» (RIR) убраны в 0.7 по просьбе Андрея — подход = вес × повторы.
- `js/progression.js` — прогрессия, чистые функции (`Progression.suggest`), тесты `node dev/test_progression.js`; в приложении `progOf`/`progText` (app.js): на «Сегодня» вес с «↑», на экране упражнения — подсказка «Пора прибавить / Цель N повторов / Сбавь». Правила: все подходы на рабочем весе (самый тяжёлый, где повторов ≥ низа диапазона; в гравитроне — самая лёгкая помощь) дошли до верха и их ≥ 2 → прибавка на шаг; иначе тот же вес, цель +1; ни один подход не дошёл до низа — сбавить (два раза подряд −10 %); дискомфорт или облегчённый день — без прибавки.
- Если тренировку не завершили, а после последнего действия прошло > 10 мин — конец = последнее действие + 1 мин.
- Комментарий к упражнению — поле `#n-text` прямо на экране, сохраняется сам. «Заменить» → список → просмотр (`sheetSwapView`: фото, техника) → «Выбрать» / «← К списку». У всех окон крестик ✕ (`.sheet-x`). Фото — `photosHTML`: целиком, на всю ширину, везде под спойлером «Фото» (Андрей просил).
- `js/muscles.js` — схема мышц (`musclesHTML`): фигура спереди/сзади (контуры react-body-highlighter, MIT), `MM[id] = [основные, помогающие]` в наших зонах (`ZONE`). В «Технике» и просмотре замены — сразу под спойлером «Фото», на экране тренировки — внутри спойлера «Фото и мышцы». Новое упражнение — добавь в `MM`.
- `js/quotes.js` — 200 фраз без авторов; `quoteFor(дата)` — по номеру тренировочного дня от 5 окт 2026, без повторов. Показ: «Сегодня» (силовой день) и первый экран тренировки.
- Взвешивание по понедельникам: `maybeWeigh` при открытии/возврате — окно «сначала взвесься», вес → `D.settings.weight` и в Рацион; на карточке понедельника строка «Сначала взвесься» (видна и заранее) или «Взвесился — N кг» (`localStorage['racion-v3'].w`, `[{d,w}]`, тот же домен). Не спрашивает, если уже есть вес за сегодня в Рационе, пропущено (`weighSkip`) или тренировка сделана.
- `js/sync.js` — копия в GitHub: тот же приватный репозиторий, что у Рациона (`godoffear/racion-data`), папка `trener/` (`trener/latest.json`, `trener/history/trener_ГГГГ-ММ-ДД.json`). Токен и репозиторий берутся из `localStorage['racion-gh']` (Андрей подключил в Рационе; общий домен) — только читаем; свой статус — `localStorage['trener-gh']` (`last`, `err`, `pending`). Отправка сама после каждой тренировки (`finishWorkout`), при «Скачать» и «Отправить сейчас»; не ушло — повтор при открытии. Фото тела не отправляются. Claude читает `trener/latest.json` через GitHub MCP (`add_repo` racion-data).
- Как считается вес (0.16): у каждого упражнения с весом (`type:'w'`) режим `D.settings.wmode[id]` — `'total'` (общий: штанга, блок, стек тренажёра) или `'each'` (на каждую сторону / одну гантель; в тоннаже ×2). По умолчанию гантели — `each`, остальное — `total` (`defMode`/`modeOf`). Переключатель — два чипа на экране упражнения. В подходе пишется `s.wm`; подсказки прогрессии, «В прошлый раз» и рекорды сравнивают только подходы в том же режиме (`sameMode`); у старых записей без `wm` режим по умолчанию. Калькулятор блинов — только для штанги в режиме `total`.
- `js/sounds.js` — `SOUNDS` (синтез Web Audio, без файлов), `playSound`/`playAlarmSound`/`playPip`, `ensureAudio` (общий `audioCtx`). Настройки в `D.settings`: `sound`, `soundVol`, `pips`. Пики на «Громко» ≤ 0,85 (без треска) — проверять при добавлении звуков.
- Плашка «Вышла новая версия» — `showUpdate` по `controllerchange`.
- Не называй глобальные функции `history`, `name`, `status` и т. п. — перекроют `window.*`.
- Без `backdrop-filter` и постоянных анимаций — греют телефон.
- Шрифты Manrope и Unbounded лежат в `fonts/` (латиница + кириллица).
- PWA: `manifest.webmanifest` (standalone, иконки в `icons/`), `sw.js` — кэш `trener-<VERSION>`, при установке кладёт всё приложение (`SHELL`) и все фото (список из `js/exercises.js` через `importScripts`); отдаёт из кэша, обновляет в фоне. Новый JS-файл — добавь в `SHELL` в `sw.js`.

## Этапы
1. Данные, программа, «Сегодня» — готово (0.2: без шагов, меньше шума).
2. Экран тренировки — готово (0.4), плюс итог, голос, путь к подтягиванию, кликабельные дни. Перенос пропущенной тренировки со сдвигом недели Андрей не хочет; талию здесь не вести (калипер — в Рационе).
3. Прогрессия — готово (0.14): `js/progression.js` + тесты. Разгрузочная неделя (раз в 7 недель, подходов вдвое меньше) — не делали, Андрей просил расписать, ответа нет.

5. PWA: установка, иконка, офлайн, плашка обновления — готово.
